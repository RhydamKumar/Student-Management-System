# Student Management System (CLI Based)

This is a simple Command Line Interface (CLI) based Student Management System project developed in C++. The project is designed to manage student records efficiently using basic CRUD (Create, Read, Update, Delete) operations. It demonstrates the use of Object-Oriented Programming (OOP), file handling, and menu-driven programming in C++.

---

## Features

- Add new student records  
- Display all student records  
- Search student by ID or name  
- Update existing student information  
- Delete student records  
- Store data permanently using file handling  
- Simple and interactive menu-driven interface  

---

- Programming Language: C++  
- Concepts Used:
  - Object-Oriented Programming (OOP)
  - File Handling

  - Loops

## How to Run

1. Clone the repository:
   git clone https://github.com/RydamKumar/Student-Management-System.git

2. Navigate to the project directory:
   cd Student-Management-System

3. Compile the code:
   g++ main.cpp -o sms

4. Run the program:
   ./sms

---

## Menu Options

When you run the program, you will see the following menu:

1. Add Student  
2. Display Students  
3. Search Student  
4. Update Student  
5. Delete Student  
6. Exit
